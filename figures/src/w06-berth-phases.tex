%  캡스톤의 w06-berth-phases.tex 를 옮긴 것이다. 바뀐 것 넷.
%    ① 단계 번호 0/1/2/3 -> 1/2/3/4, 이름도 모델의 phase 신호 그대로
%       TRANSIT / ALIGN / BERTH / MOORED
%    ② 회전하는 부두 (psi_t, s) 를 버린다 — W06 의 부두는 북남으로 고정이다
%    ③ **선체 위치와 선수각을 전부 실측값으로 둔다.** 캡스톤은 보기 좋은 자리에
%       배를 놓았지만, 여기 좌표는 W06_G_berthing 이 찍은 수치다. 그래서 두 전략이
%       같은 곳에서 갈라지는 것이 그림에서 그대로 보인다
%    ④ "일하는 추진기" 산문 칸은 `.md` 로 옮긴다 — 그림에는 잰 수치 한 줄만 남긴다
%
%  실측 (W06_read('W06_H_berth', 'psi_berth', ..., 'T_final', 150))
%      alongside   p2 (38.622, 8.768) -22.42    p3 (39.450, 8.464)  -0.08
%                  mid (39.989, 4.663)   0.00   v = -0.350   p4 (39.999, 1.344)
%      bow-first   p2 (38.622, 8.768) -22.42    p3 (39.780, 8.255) -89.85
%                  mid (39.957, 3.990) -90.00   u = +0.800   p4 (39.992, 1.598)
%
%  화면 = NED 를 위에서 본 것.  screen x = east,  screen y = north.
%  축척 1 m = 6 mm. 선체는 실척이다 (LOA 2.0 m = 12 mm, 폭 1.08 m = 6.48 mm).
%
%  호의 각도는 **요구한 회전**이다. W06_G_berthing 이 'turn asked' 로 찍는 것이
%  |psi_berth - psi(2 단계 진입)| 이고, 그래서 22.4 / 67.6 이다. 선체 글리프의
%  선수각은 **실측**(-0.08, -89.85)이지만 호의 끝각은 **명령값**(0, -90)에 둔다 —
%  그래야 호가 라벨의 수치와 정확히 같은 각을 쓸어 낸다.
%  실측으로 잰 회전은 22.34 / 67.43 이다. 강의가 인용하는 것은 러너가 찍는 쪽이다.
%
%  회전 방향 — 그려 놓고 확인한 것 (§15-28)
%      화면각 = 90 - psi 이므로
%      (가) psi -22.42 -> 0   이면 화면각 112.42 -> 90,  **줄어든다** = 시계방향
%      (나) psi -22.42 -> -90 이면 화면각 112.42 -> 180, **늘어난다** = 반시계
%      TikZ 의 arc(a:b:r) 은 b 가 작을 때 시계방향이다.
%
%  주석만 한국어다. 조판되는 글자에 한글을 넣으면 pdflatex 이 멈춘다.

%  선체 하나, 실척 / one hull, to scale.  #1 north  #2 east  #3 psi [deg]  #4 colour
%  shift= 에는 좌표 매크로를 줄 수 없다 — 숫자 식으로 푼다 (§15-바로 아래 교훈)
%
%  꼭짓점은 **다섯**이다 — 좌현 선미, 좌현 어깨, 뱃머리, 우현 어깨, 우현 선미.
%  넷만 적고 cycle 하면 우현 어깨에서 좌현 선미로 대각선이 그어져 선체가
%  **연꼴**이 된다. 실제로 그렇게 그려 놓고 한 번 넘어갈 뻔했다 (교훈 lxxxii).
\newcommand{\hullf}[4]{%
  \begin{scope}[shift={({((#2) - 1.2)*\PS},{((#1) - 40)*\PS})}, rotate={90 - (#3)}]
    \fill[white]                  (-6,-3.24) -- (3.3,-3.24) -- (6,0) -- (3.3,3.24) -- (-6,3.24) -- cycle;
    \fill[#4!14]                  (-6,-3.24) -- (3.3,-3.24) -- (6,0) -- (3.3,3.24) -- (-6,3.24) -- cycle;
    \draw[#4, line width=0.6pt]   (-6,-3.24) -- (3.3,-3.24) -- (6,0) -- (3.3,3.24) -- (-6,3.24) -- cycle;
    \draw[#4, line width=0.3pt]   (-6,0) -- (6,0);
  \end{scope}}

%  돌기 전의 선체 — 외곽선만. 돌고 난 선체가 그 위에 그려져 일부를 가린다
\newcommand{\hulld}[3]{%
  \begin{scope}[shift={({((#2) - 1.2)*\PS},{((#1) - 40)*\PS})}, rotate={90 - (#3)}]
    \draw[soft, line width=0.45pt, densely dashed]
         (-6,-3.24) -- (3.3,-3.24) -- (6,0) -- (3.3,3.24) -- (-6,3.24) -- cycle;
  \end{scope}}

%  두 패널이 **똑같이** 쓰는 무대. 다른 것은 선체의 선수각뿐임을 보이려는 것이다
%  세로 예산 — 노드를 놓기 전에 전부 적어 둔다 (교훈 lxxvii)
%      36    제목 위, 두 줄이 아래로 자라 26 까지
%      22    부두 띠 위
%      18    호 라벨 줄 (두 줄 아니라 한 줄, 21.5 까지)
%      13~15 호
%      9.8   속도 라벨 (두 줄, 16.5 까지)
%      8.5   속도 화살표
%      0     선체 줄 — **패널마다 다르다**
%                (가) psi=0   : 뱃머리가 북쪽. 세로 ±6,   가로 ±3.24
%                (나) psi=-90 : 뱃머리가 서쪽. 세로 ±3.24, 가로 ±6
%                한 줄로 "±3.3" 이라고 적어 두었다가 (가) 패널의 단계
%                번호가 선체 **속에서** 시작했다 (교훈 lxxxiii)
%      -7.5  단계 번호 줄 — (가) 에서 1.4 mm, (나) 에서 4.2 mm 뜬다
%      -8.3  2 ALIGN
%      -22   1 TRANSIT
%      -30   부두 띠 아래
%      -42   패널 주석
%      -56   구분선
\newcommand{\scene}{%
  \begin{scope}
    \clip (-16,-30) rectangle (-7.2,22);
    \fill[black!5] (-16,-30) rectangle (-7.2,22);
    \foreach \k in {-44,-40,...,24}
      {\draw[soft, line width=0.3pt] (-16,\k) -- (-7.2,{\k+10});}
  \end{scope}
  \draw[ink, line width=0.9pt] (-7.2,-30) -- (-7.2,22);
  \node[un, anchor=north] at (-11.6,-30.4) {quay};
  %  1 단계가 들어오는 길 — 방위 atan2(8.2-25, 40-0) = -22.8 deg
  %  화살촉은 2 단계 선체의 **밖**에서 멈춘다. (47.4,-12.9) 는 선체 중심에서
  %  뒤로 5.0 mm 라 반길이 6 mm 안쪽, 즉 선체 속이었다 (교훈 lxxii).
  \draw[bodyc, line width=0.3pt, densely dotted] (57.0,-35.6) -- (54.6,-29.9);
  \draw[bodyc, line width=0.7pt, -{Stealth[length=4pt,width=3pt]}] (53.6,-27.7) -- (49.0,-16.6);
  \node[io, anchor=east] at (44,-22) {\textbf{1} \textsc{transit}};}

%  2 단계에 들어서는 순간의 선체 — 두 전략이 **같다**.
%  이것은 \scene 이 아니라 **실선 선체 뒤에** 그린다. 2 단계는 2.62 s 뿐이라
%  38.622,8.768 과 3 단계의 39.450,8.464 이 0.87 m 밖에 안 떨어져 있고, 먼저
%  그리면 실선 선체가 점선을 덮어 **모서리만 삐져나온 부서진 상자**로 읽힌다.
%  위에 얹으면 같은 선체가 제자리에서 22.4 deg 돌았다는 것이 그대로 보인다.
\newcommand{\alignghost}{%
  \hulld{38.622}{8.768}{-22.42}
  %  선체의 화면 최대 x 는 45.4 + 5.29 = 50.7 이다. 49 에 anchor=west 로 두면
  %  라벨이 선체 안에서 시작한다.
  \node[io, anchor=west] at (51.5,-8.3) {\textbf{2} \textsc{align}};}

%  판정원은 맨 나중에 그린다 — 선체에 가려지지 않게
