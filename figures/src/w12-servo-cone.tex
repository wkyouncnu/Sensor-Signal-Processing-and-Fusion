%  (왼쪽) |delta_i| <= alpha_max 는 atan2 로 쓰면 비선형으로 보이지만, 그 단위의
%         추력 **부호**를 먼저 정해 두면 직선 둘이다. 그래서 QP 다.
%  (오른쪽) 앞으로 미는 반쪽과 뒤로 미는 반쪽을 합친 것은 **볼록하지 않다** —
%         두 점을 잇는 선분이 집합을 벗어난다. 그림이 그 선분을 직접 그린다.
%         볼록하지 않은 것은 조각 2^4 = 16 개로 **정확히** 덮인다.
%
% alpha_max = 45 deg 이므로 tan = 1 이고 벽은 f_y = +-f_x 다. 이 그림의 좌표는
% 그것을 그대로 쓴다 — 45 도가 아닌 값으로 바꾸려면 기울기 t 를 함께 고친다.

% 앞 그림(w12-allocation-chain)에서 배운 것 둘을 여기서도 지킨다.
%  (1) 글자는 상자/칸 **안**에 둔다. 칸 밖에 두면 옆 칸을 침범한다.
%  (2) 칸 둘의 중심 간격(7.0 cm)은 칸 폭(약 4.8 cm)보다 넉넉히 넓게.

   solving all sixteen returns the true optimum.};
