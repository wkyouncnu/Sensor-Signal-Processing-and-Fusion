### $N>0$ 은 **시계방향** — 그림 둘을 고쳤다 — 완료 (2026-10-13, 사용자 지적)

> 사용자: *"이 그림이 맞아? N 방향이 시계방향이 + 아니야?"*

맞다. $z_b$ 가 아래(NED)이므로 $N$ 은 $+z_b$ 둘레이고, 오른손 법칙은 $+x \to +y$,
곧 선수가 우현으로 간다. 위에서 내려다본 그림($x$ 위, $y$ 오른쪽)에서 그것은 **시계방향**이다.
논증만 믿지 않고 플랜트로 확인했다 — $F_L = 40 > F_R = 10$ 에서
$N = +11.850$ N·m, `otter.m` 이 $\dot r = +0.28904$ rad/s².

| 그림 | 전 | 후 |
|---|---|---|
| `w03-thrust-to-shafts.svg` | `arc (-60:-18:2.0)` 반시계 | `arc (-18:-60:2.0)` 시계 |
| `w05-allocation.svg` | `arc (-70:-18:1.0)` 반시계 | `arc (-18:-70:1.0)` 시계 |
| `w03-why-T.svg` | `arc (58:6:0.80)` | 이미 맞았다 |

`figures/src` 의 `arc (` 를 전부 훑어서 찾은 것이고, **같은 지뢰를 두 번 밟았다** —
`w01-pqr.svg` 의 roll 과 yaw 가 반대였던 것이 첫 번째다. 그래서 `CLAUDE.md` §4 규칙 6-2 와
새 규칙 §15-28 에 적었다: 회전 화살표는 화면 기저로 축을 풀어 **계산해서** 정하고,
TikZ `arc` 는 **끝 각이 작을 때** 시계방향이며, 끝내기 전에 `arc (` 를 grep 한다.

같은 지시로 W05 §5-7 의 배분 그림을 `w05-allocation.svg` 에서 `w03-why-T.svg` 로 바꿨다
(사용자: *"W05에도 이 그림 넣어줘"*) — 읽는 표는 §5-7 관점으로 다시 썼다. 그 결과
`figures/w05-allocation.svg` 는 **본문에서 아무도 부르지 않는다.** 지우지 않고 남겨 두었다.

세션 설정도 함께 내렸다 — auto-compact 를 95 % 에서 (사용자: *"95 퍼센트 되면
auto -compact 해줘"*). `~/.claude/settings.json` 의 `modelSettings` 아래
`autoCompactWindow: 190000` + `autoCompactEnabled: true`. 창 크기는 퍼센트가 아니라

### W05 에 2025년 PPT·Fossen 캡처 열한 장과 Lyapunov 유도 — 완료 (2026-10-17, 사용자 지시)

> 사용자: *"이제까지 이미지들을 적당한 크기로 그냥 강의 자료 해당 부분에 넣어줘…유도 부분은
> 그대로 옮겨주고"*, 그리고 *"리아프노프 안정도 판정 원리에 대한 것도 간단히 추가 언급이 필요할듯"*

2026-10-13 에 PPT 59–71 쪽의 **내용**을 §5-5 에 녹였고, 이번에는 그 **슬라이드 자체**를
같은 자리에 실었다. 새 폴더 `figures/refs/` 에 `w05-ref-*` 열한 장이고, TikZ 로 만드는
`figures/*.svg` 와 섞이지 않게 분리했다.

| 슬라이드 | 들어간 자리 |
|---|---|
| 선수각형 LOS 기하 · 오차 운동방정식 | 6번 줄 — $\dot y_e = U\sin(\chi-\pi_p)$ 바로 뒤 |
| 횡방향 오차 동역학 + Lyapunov | **새 7b 번 줄** |
| 비선형 ILOS + `ILOSchi` | **새 9b 번 줄** |
| 보통 ILOS | "보통 적분은 왜 안 되는가?" |
| 두 ILOS 형태 · 과도응답 비교 | 두 적분기 그림 뒤 |
| 침로 대 선수각(두 구조) · 영속력 | 침로/선수각 콜아웃 뒤 |
| 크랩각 추정과 B777 · 선수각형 법칙 | "크랩각을 재면 되지 않는가?" |
| 조류의 영향(2025년 측정) | 실험 5-5a 의 2025년 비교 콜아웃 안 |

**유도는 전사했다.** Fossen (2021) p. 362 의 (12.96)~(12.100) 을 9b 번 줄에 LaTeX 으로
옮겼다 — 책 쪽을 이미지로 싣지 않는다(§4 규칙 1). 7b 번 줄은 조류가 없을 때의
$\dot V = -U (y_e)^2/\sqrt{\Delta^2+y_e^2} < 0$ 이고, 그 앞에 **Lyapunov 판정 원리 상자**를
두었다 — 왜 필요한가(전달함수가 없다) · 원리(에너지) · 조건 셋의 표 · 결론 · 주의 둘
(충분조건이지 필요조건이 아니다, 물리적 에너지일 필요가 없다).

곁다리로 **크랩각 기호를 통일했다.** §5-5 뒷부분이 크랩각을 $\beta_c$ 로 쓰고 있었는데
이 볼트에서 `beta_c` 는 **조류 방향**이다(`W05_0_setup.m`). 본문 여섯 자리와
`figures/src/w05-course-vs-heading.tex` 여섯 자리를 $\beta$ 로 바꾸고 SVG 를 다시 뽑았다.
`w04-course-crab.tex` 의 `\Delta\tan\beta_c` 와 낡은 "§5-7" 참조도 같이 고쳤으므로
W04 PDF 도 다시 뽑았다.

`vault_check.sh` 16번(범례 표)이 `| On the slide |` · `| 슬라이드에서 |` 를 인정하도록
넓혔다 → 새 규칙 §15-40. 영문·국문 양쪽에 같은 열한 장이 들어갔고 PDF 넷을 다시 뽑았다.

### 사용자의 한국어 참고 그림 셋을 영어로 다시 그렸다 — 완료 (2026-10-17, 사용자 지시)
