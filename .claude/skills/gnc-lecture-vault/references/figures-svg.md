## 3-1. 3차원 그림 — 좌표를 눈대중으로 놓지 않는다

선체 + 축 + 모멘트, 좌표계 회전, 추진기 배치처럼 **3차원을 그리는 그림**은
사영을 하나 정해 **계산해서** 찍는다. 전체 규칙은 `standing-orders.md` §3-2 이고, 요점은 셋이다.

1. 화면 오른쪽 $\hat r$, 화면 아래 $\hat d$ 를 3차원의 **직교 단위벡터**로 잡는다.
   점 $v$ 는 $(v\cdot\hat r,\ v\cdot\hat d)$ 에 찍힌다
2. **축 $\hat a$ 둘레의 모멘트는 $\hat a$ 에 수직인 평면 위의 원**이다.
   사영하면 타원이 되고 **중심은 반드시 축선 위**에 있다.
   $p(t)=C+\cos t\,\hat u+\sin t\,\hat w$ 를 꺾은선으로 뽑는다 — SVG `A` 호로는 안 된다
3. 계산은 `_tools/` 에 스크립트로 남긴다. 본보기: `_tools/w01_6dof_arcs.awk`

```awk
# 켤레 반지름 (ux,uy), (wx,wy) 인 타원호. u 에서 w 로 도는 것이 양의 방향이다.
for (i = 0; i <= n; i++) {
    t = (t0 + (t1 - t0) * i / n) * PI / 180
    printf "%s%.2f,%.2f ", (i ? "L " : "M "), \
        cx + cos(t)*ux + sin(t)*wx, cy + cos(t)*uy + sin(t)*wy
}
```

축선을 타원 중심까지 **점선으로 연장하고 중심에 점을 찍는다.** 그것이 없으면
독자는 원이 어느 축 둘레인지 알 수 없다.

## 4. 그림만 던지지 않는다

문서에는 **그림 읽는 법**을 표로 덧붙인다.

```markdown
![LOS 유도 기하](../figures/w07-los-geometry.svg)

| 기호 | 뜻 |
|---|---|
| $\pi_p$ | 구간 방위 — 이전 웨이포인트에서 다음 웨이포인트를 본 방향 |
| $y_e$ | 횡방향 오차 — 경로에서 벗어난 거리 |
| $\Delta$ | 전방주시거리 — 작으면 공격적, 크면 완만 |
```

- 그림 1장당 이론 절 하나. 한 절에 3장을 넘기지 않는다
- 같은 개념을 글과 그림으로 두 번 설명하지 않는다. 그림이 있으면 글을 줄인다
